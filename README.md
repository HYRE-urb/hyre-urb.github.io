# HYRE 홈페이지

| 폴더/파일 | 내용 |
|---|---|
| `index.html` | 사이트 전체 (Home / About HYRE / Curriculum / Project / Network / Recruiting) |
| `img/` | 로고, 사진, 리포트·IM 표지 |
| `fonts/` | KoPubWorld 돋움 Light·Medium·Bold |
| `reports/` | 리포트 페이지 이미지 (리포트별 폴더, p01.jpg ~) |

## 자주 고치는 곳: index.html 아래쪽 `✏️ 기수·학기마다 여기만 고치면 됩니다`
`SITE`(모집), `TIMELINE`(일정), `SUB1`/`SUB2`(서브 프로젝트), `IM`(메인 IM), `MEMBERS`(학회원·운영진·팀)

## 리포트 추가
PDF를 페이지별 JPG로 바꿔 `reports/폴더이름/p01.jpg ...`로 올리고, `SUB1` 항목에 `"pages":"reports/폴더이름", "n":페이지수`를 넣습니다.

## 배포
GitHub 저장소에 이 폴더 내용을 올리고 Settings → Pages → Branch: main / (root). 파일이 많으니 GitHub Desktop 사용을 권장합니다.
